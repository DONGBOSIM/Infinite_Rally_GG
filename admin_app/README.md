# 무한랠리 관리자용 앱 (admin_app)

배드민턴 동호회 '무한랠리'의 관리자용 모바일 애플리케이션입니다.

## 주요 기능
- 회원 명단 관리 (급수, 성별, 참석 여부 체크)
- 50여 명 회원 대상 자동/수동 공평 매칭 알고리즘
- Firebase Firestore 실시간 업로드
- 당일 웹페이지 접속 URL 동적 QR 코드 생성 및 화면 표시

## 기술 스택
- Framework: Flutter (Dart)
- Target: Android (APK 빌드는 GitHub Actions 연동 예정)
- Backend: Firebase Firestore
